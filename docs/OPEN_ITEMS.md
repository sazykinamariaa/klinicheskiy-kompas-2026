# Открытые вопросы и решения разработчика на проверку

Актуальный полный список выводится админ-панелью: `GET /api/admin/config/waiting` (сейчас 66 позиций). Ниже — то, что влияет на работу.

## Ждём данных (нужны от команды / врача / юристов)

* Реестр дежурных (`clinic_settings.json` → `on_duty.roster`) — имена и телефоны. Пока первую волну красного алерта получают пользователи с `duty_role`.
* Проверенный телефон психологической помощи (кнопка на экране поддержки показана как ожидающая данных); региональные линии.
* ОХЛП препарата: коды МКБ-10 показаний, часть взаимодействий, особые группы. Правило D-07 (алкоголь / беременность) не исполняется, пока не подтверждено.
* Текст согласия на обработку ПДн и срок хранения данных (юридическая часть). Сейчас стоит заглушка `stub-0`.
* Права на цифровое воспроизведение HCL-33, LSAS, RUS-AUDIT (сейчас справочно, без текста вопросов). Исключённые по юр. аудиту шкалы в приложении не используются.
* Врач, подписывающий утверждения (`approval.json`): ФИО и подпись.

## Решения разработчика, требующие проверки врачом (`draft_by_dev_pending_review`)

Всё лежит в `config/rule_bindings.json`; новых клинических значений там нет, только связка текста правил с кодом:

1. Пункт PHQ-9 считается выраженным симптомом при ответе «более чем половину времени» и чаще (≥2).
2. Нижние границы длительности депрессивных симптомов взяты из формулировок вариантов ответа на вопрос 2.
3. Пул симптомов ГТР взят из критерия B по МКБ-10 (статус `verify`).
4. Правило D-07 и оранжевый сигнал от кнопки «Мне тяжело» (формулировка из `daily_checkin.json`).
5. Два дополнительных поля клинического профиля: `second_indication_confirmed` (второе показание для F41.9/F43.9) и `meds_confirmed` (список препаратов проверен врачом).
6. Справочник препаратов `config/med_dictionary.json` (36 записей): классы взяты из листка Авиандра; препараты вне справочника дают «проверка не завершена».
7. Закрытие алерта: ключи полей API (подписи — дословно из `alert_rules.json`).

## Известные ограничения

* Импорт истории: на 6 синтетических текстах точность 0,94, полнота 1,0 (`docs/import_eval.json`). Фраза «ранее получал моклобемид, отменён» предлагается как препарат — осознанно в сторону осторожности (ИМАО важен для проверки), врач отклоняет вручную.
* Замеры (`docs/benchmarks.md`) сняты на одном процессе с SQLite; для боевой нагрузки пересчитать на PostgreSQL.
* Интерфейс проверен прогоном в браузере (вход по ролям, карточка, решения, алерты, приглашение и анкета пациента); аудита доступности скринридером не было.
